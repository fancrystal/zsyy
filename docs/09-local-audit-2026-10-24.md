## 6. 本次复现并修复的问题

### HTTP 手机环境请求编号兼容

原先商品打开和后台发券直接调用 `crypto.randomUUID()`，该 API 不可用时操作报错。组件测试以保留 `getRandomValues`、移除 `randomUUID` 的环境复现错误后，新增共享请求编号函数，使用随机字节生成兼容键。修复后商品弹层和发券组件测试通过。未声称已完成真机 HTTP 测试。

### 最大市场固定标在第一行

原先手机团队与后台计奖口径均按行号 0 标最大市场。提高第二个市场累计消费后，标签仍在第一行，和公式不一致。现按实际累计消费选最大市场，并列按用户 ID 升序选一个，双端按市场 ID 标记。新增回归测试验证第二行成为最大市场。

另修复了两处旧设计文档末尾的中文乱码，恢复演示限制和历史验证说明。
