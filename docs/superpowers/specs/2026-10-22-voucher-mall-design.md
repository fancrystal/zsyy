# 产品券商城设计基线

日期：2026-10-22。工作目录：`D:\work\zsyy`。

## 用户确认的目标

建设手机访问的产品券商城，并配独立管理后台。沿用 `D:\work\mskj\backups\project\mskj` 的 Vue 3、Vite、Node.js、Express、MySQL、Redis、pnpm workspace 技术路线，在当前目录重新搭建精简项目，按阶段推进。

手机端只设首页公司介绍、商城、订单、个人管理四个底部页面。个人管理包含产品券、资料、地址、邀请码、团队和返利；管理后台是独立系统。

产品券由后台发放，也允许开发者维护数据库。没有充值及线上现金交易。商品购买只记录购买结果，用户有默认收货地址，线下发货。下单扣券直接计入消费，无取消、退款或确认收货。

邀请码注册形成一对多上下线关系，每人只有一个上线，绑定后用户不更换。开发者可在数据库维护。每个直属下线连同其所有后代构成一个子市场。

最大子市场按历史累计消费动态判断。累计应得返利为排除一个最大市场后的其他市场累计消费之和乘 10%，减去已发累计后仅补发差额。返利以产品券进入余额，消费变化时触发重算，每天固定时间补查。

## 实施方案

用户端、后台和单体 API 分离为三个应用，通过 workspace 管理。MySQL 事务保护订单、余额、流水、市场消费和返利的一致性。消费订单是市场累计的来源，返利采用累计目标与唯一流水防重。Redis 辅助运行协调，不能代替数据库账目。

业务规则见 [业务与返利规则](../../02-business-rules.md)，模块边界见 [框架设计](../../03-architecture.md)，数据结构见 [数据库设计](../../04-database-design.md)，交互见 [API 设计](../../05-api-design.md)。
