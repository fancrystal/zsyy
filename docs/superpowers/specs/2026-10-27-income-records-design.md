# 收益记录

用户确认：网站内所有用户可见的旧称统一为“收益”；邀请链接不改。

个人管理入口改为“收益记录”。弹窗顶部展示累计已到账总收益，下方分别展示“推荐收益（直接推荐20%）”和“团队佣金（团队收益10%）”的累计金额、到账时间和金额明细，独立分页。总收益等于两类实际到账金额之和，不包含后台发券、消费和未到账金额。团队佣金仍使用排除最大市场后的累计差额算法。

后台聚合全部到账流水，不能使用前端当前页求和。查询仅限当前登录用户。已有账本标识和结算规则保持兼容，旧流水标题及说明在输出时统一显示收益文案。前台、后台、演示数据、规则说明和错误文案同步更新。

验证涵盖混合流水、分页总额、用户隔离、退出后的迟到响应、分类明细和前后台可见文案。运行组件测试、后端集成测试和构建；发布状态单独报告。

“我的团队”弹窗的收益规则必须同时说明：直属推荐用户完成订单后，推荐人获得订单金额的 20%，仅限直接推荐关系；团队佣金排除累计消费最高的一个子市场，其他子市场累计消费的 10% 计入收益，扣除已发收益后补发差额；本人消费只计入上级市场。
