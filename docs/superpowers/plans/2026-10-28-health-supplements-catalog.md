# Health Supplements Catalog Implementation Plan

**Goal:** 将商城目录切换为两款 399 元健康营养商品，并在详情中展示对应长图。

**Architecture:** 新增可重复运行的目录维护脚本，按商品名称更新两款指定商品并下架其余商品。商品数据增加详情长图字段，用户商城隐藏分类标签并在详情弹窗渲染长图。

**Tech Stack:** Vue 3、Node.js、MySQL、Vitest、node:test、ImageGen。

## Global Constraints

- 两款商品均为 39900 最小券单位。
- 仅保留两款指定商品为上架状态；历史订单快照不变。
- 原始长图完整显示在对应商品详情底部；用户端不显示分类栏。
