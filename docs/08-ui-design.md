# 第一版 UI 设计

## 参考与范围

参考本机 mskj 的 `mobile-h5/src/App.vue`、`TabBar.vue`、`ProfilePage.vue` 和商城卡片。保留深蓝主色 #1e3a8a、亮蓝 #3b82f6、浅灰底 #f8fafc、白卡片、细线图标及固定底部导航；商城当前源码局部采用橙色，这里统一回深蓝，少量金色用于产品券与返利。

用户已同意产品整体设计，本轮按“UI 类似 mskj”落地本地界面预览。只搭建前端和浏览器演示数据，不连接真实钱包、认证或数据库，不发布网站。

## 方案选择

采用 mskj 风格的精简适配：沿用色彩、资产卡与圆角层次，重新组织四页信息。相比整页复制可避免带入不相关业务；相比另起视觉风格更符合用户指定参考。

## 页面

- 首页：品牌栏、深蓝品牌介绍主视觉、品牌理念、公司介绍和商城入口。不编造营业资质、销量、创办年份或实际服务承诺。
- 商城：余额摘要、商品搜索、分类标签、两列商品卡、详情和数量确认弹层。原项目的三张商品图片仅用于本地演示，不表示正式上架或功效背书。
- 订单：消费摘要、搜索、购买记录和详情弹层；无物流、确认收货、退款取消按钮。
- 管理：头像及邀请码、产品券资产卡、团队三项摘要、默认地址、邀请、资产明细和返利记录。子市场列表标记最大市场，展示累计差额规则。
- 独立后台：深蓝侧栏、页面标题、统计卡、订单/用户/商品/发券/内容/返利/任务视图。窄屏可横向切换菜单，表格可在容器内滚动。

## 交互及状态

演示下单校验正整数数量、余额、上架状态和默认地址，余额与订单在一个本地状态更新中保存；保存失败提示，不显示虚假成功。可编辑默认地址、查询记录、复制邀请码，后台可演示发券、编辑商品、切换上架及编辑公司介绍。各视图都保留空结果提示。

所有页面明显标记“界面预览 · 演示数据”，浏览器数据可通过显式确认重置。演示前端没有真实认证权限，不能作为生产商城运行。实时多级返利与每日任务留给后续后端实现，页面只展示演示团队统计。

弹层使用原生 dialog，支持 Esc、焦点限制和关闭按钮；输入有标签、按钮有明确语义。兼容 320px 起手机宽度、安全区和减少动画设置。前端首版不依赖在线字体、在线图片或付费服务。

## 验证

演示模型用 Node 内置测试验证扣券、失败不变更、重复提交防重、价格变化、历史快照和发券。布局使用构建验证并尽可能进行真实浏览器检查。正式数据库账务、账号安全、任务调度不属于本轮已实现功能。

## 演示状态限制

手机与后台同源时通过 localStorage 和 storage 事件同步，适合顺序体验；不保证多个标签页同时写入时的账务原子性。正式系统必须使用后端 MySQL 事务和唯一约束实现并发安全，不能将当前演示存储用作生产账务。
